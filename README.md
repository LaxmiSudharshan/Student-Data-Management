A simple Python desktop application built using Tkinter to manage student records.
It allows you to add, update, delete, and view student details, with all data stored in a CSV file for easy access and portability.

Features

Add new student records

Update existing records

Delete student data

Auto-save all changes to a CSV file

Clean and simple Tkinter interface

Listbox to view all saved records

This project is perfect for beginners learning Tkinter, file handling, and building basic GUI applications in Python.
